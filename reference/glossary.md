# Engineering Glossary — Living Reference

| Term | Short definition | Practical question |
|---|---|---|
| Abstraction | Hide irrelevant detail behind a useful model | What details can I safely ignore here? |
| API | Defined interface through which software components interact | What contract does caller and provider share? |
| Application | Software performing a user/business task | What behavior does it provide? |
| ARP | IPv4 local-link address resolution protocol | How is next-hop MAC found on local Ethernet? |
| Backend | Server-side logic/data handling | What happens after the request arrives? |
| CIDR | Prefix-based notation for IP networks | Which bits identify the network? |
| Client | Initiator/consumer of a service | Who sends the request? |
| DNS | Distributed name system | How is a name resolved? |
| Gateway | Next-hop router for traffic to another network | Where does this packet go next? |
| HTTP | Web application protocol | What method, path, headers and status? |
| IP | Network-layer addressing and packet forwarding protocol | What destination address is in the packet? |
| Kernel | Core OS component managing hardware and resources | Which operations need kernel mediation? |
| Port | Transport identifier for service endpoint | Which transport endpoint is targeted? |
| Process | Executing program instance with resources/state | What is running and under which identity? |
| Route | Entry/policy determining next hop and interface | How does the host choose the path? |
| Shell | Command interpreter | How is command text parsed and executed? |
| Socket | OS networking endpoint abstraction | Which local/remote endpoint and state? |
| TCP | Reliable, ordered byte-stream transport | What connection state and retransmission? |
| TLS | Cryptographic transport protection and authentication | How are identity, keys and integrity established? |
| UDP | Datagram transport without TCP's delivery/order guarantees | Is the application handling loss/reordering? |
| URL | Resource locator with scheme and components | Which scheme, host, port, path and query? |

Add new entries as they are taught. Definitions are concise; deeper notes belong in session pages.
